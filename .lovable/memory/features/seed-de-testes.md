name: Seed de dados de teste
description: Dados demonstrativos preenchidos; criação de contas fictícias e vínculos entre elas aguardam o usuário criar as contas
type: feature
---
A criação de contas fictícias e todo dado que dependa dessas novas contas deve aguardar o usuário criá-las manualmente.
Os demais módulos já possuem dados demonstrativos preservando os registros existentes. As funções de seed verificam a existência dos dados antes de inserir novamente.

**Status atual:** não executar funções que criam usuários até o usuário informar que as contas manuais estão prontas. O botão "Popular dados de teste" permanece removido da interface.

Documentação completa em `GUIA_DE_TESTES.md` na raiz do projeto.
